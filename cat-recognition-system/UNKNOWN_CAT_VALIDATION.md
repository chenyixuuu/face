# 未知猫拒识：validation 内部实验

日期：2026-09-17

## 结果与决定

在“每只已知猫登记 2 张照片”的模拟中，用校准组把未知猫误接受率限制在约 1%，阈值为 `0.8324798346`。在身份不重叠的内部核验组上：

- 未登记猫照片 12,946 张，误接受率 **0.99%**，拒识率 **99.01%**。
- 已登记猫查询 7,037 张，无拒识时 Top-1 为 **78.51%**；采用该阈值后，只有 **30.94%** 的查询被正确接受，**68.82%** 被拒识。

因此，这个阈值**不能直接作为校园系统的自动识别阈值**：虽然未知猫误接受较低，但会拒绝太多已登记猫。当前产品应返回 Top-3 候选并由人确认；低相似度时显示“无法确认/可能是新猫”，而不是自动写入正式档案。

## 协议

1. 仅使用原始 validation embedding 与已训练好的 Triplet 残差适配器；最终 test 没有读取。
2. 排除先前标记的 418 个跨身份近重复候选相关 ID；剩余至少有 3 张照片的 11,749 个 ID 参与。
3. 用固定种子 `20260917` 按身份哈希排序，交错分为校准已知、校准未知、核验已知、核验未知四组，互不重叠。已知身份前 2 张按路径排序的照片建 gallery，其余做查询；未知身份所有照片仅作查询。
4. 在校准未知组选择满足目标误接受率不高于 1% 的最低阈值；固定阈值后才计算核验组指标。

两组 gallery 分别有 2,938 和 2,937 个身份，规模接近。结构化结果见 `run_artifacts/adapter_triplet_w020_v1/validation_unknown_rejection_v1.json`。

## 限制

这是**同一 validation 内部的模拟核验**，不是完全独立的最终泛化评估：现有模型本身曾用原始 validation 选型。随机形成的未知猫也不等于校园实拍新猫。阈值不可直接迁移到不同登记规模、光照、拍摄距离或设备；后续需要独立校园样本来校准和验证。评估只覆盖特征检索，不覆盖猫脸检测失败、图片质量或人工审核效率。
