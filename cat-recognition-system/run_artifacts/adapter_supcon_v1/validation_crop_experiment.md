# Validation 裁剪与近重复审计

日期：2026-09-14

## 约束

- 只使用 validation，不重新查看或使用 test 调参。
- 不覆盖原始图片、已有 embedding、模型权重或既有报告。
- 裁剪对照使用相同 gallery 和 query，避免因检测成功样本更容易而产生选择偏差。

## 近重复审计

- validation 图片：60,292 张。
- 跨身份 dHash 距离不超过 4：349 组，涉及 418 个身份。
- 距离 0/1/2/3/4：98/42/32/40/137 组。
- 98 组 dHash 距离为 0 的图片字节 SHA-256 均不同，属于视觉近重复候选，不是字节完全相同。
- 前 20 个高置信错误身份对中有 10 对被审计直接命中。

感知哈希只能生成候选，不能自动证明两张图片一定是同一只猫。后续需要保留人工复核。

## 中心裁剪

冻结 DINOv2，一张 gallery/身份：

- 原图拉伸流程：Top-1 约 38.73%，Top-3 约 47.22%。
- 保持比例后中心裁剪：Top-1 37.66%，Top-3 46.30%。

中心裁剪没有提升，当前否决。

## 猫脸级联裁剪

- OpenCV extended frontal cat-face cascade 检出 41,061/60,292 张，覆盖率 68.10%。
- 严格配对子集：11,644 个 gallery 身份、26,931 个 query。
- 同一子集原图：Top-1 46.99%，Top-3 56.23%。
- 同一子集猫脸裁剪：Top-1 44.80%，Top-3 53.93%。

传统级联检测覆盖率不足，且配对指标下降，当前否决。

## 结论

当前瓶颈优先是跨身份近重复与疑似标签冲突，而不是简单裁剪。下一步应生成排除/合并候选清单，在不修改原数据的前提下重新计算干净 validation 指标。若未来继续研究裁剪，应使用专门标注训练的猫脸检测器。
