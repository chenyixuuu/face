# 网页版运行说明

## 服务器启动

在远程服务器 Termius 中执行：

```bash
cd ~/face_recognition_baseline
conda activate face310
python scripts/web_app.py
```

看到 `Running on http://0.0.0.0:5000` 后，网页服务已经启动。关闭 Termius 窗口或按 `Ctrl+C`，服务会停止。

## 从自己电脑打开

网页服务默认只在服务器端口 5000 监听。为了避开 macOS 已占用的 5000 端口，在本机另开一个终端执行下面的命令，把本机 5001 转发到服务器 5000：

```bash
ssh -N -L 5001:127.0.0.1:5000 -p 2006 cx@49.232.174.36
```

然后在浏览器打开：

```text
http://127.0.0.1:5001
```

这个窗口保持打开，关闭后网页就无法访问。

## 使用顺序

1. 在“登记新人员”中填写姓名，一次选择 3 到 5 张照片，点击“登记”。
2. 确认页面显示登记成功。
3. 在“识别照片”中选择另一张照片，点击“开始识别”。
4. 如果没有检测到人脸、照片中有多人或脸部角度太偏，按照页面提示重新拍摄。

照片和 embedding 会保存在服务器项目目录的 `data/people/` 和 `data/registry.json` 中。
