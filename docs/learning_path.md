# 从零开始：人脸识别项目学习路线

## 学习目标

不是先学会所有深度学习理论，而是先建立一张“我知道自己在做什么”的地图。

最终你应该能回答：

- 这个项目有哪些文件？
- 程序从哪里开始运行？
- 图片怎么进入程序？
- 模型在程序里扮演什么角色？
- 输出结果怎么看？
- 报错时大概知道是路径、环境、代码还是模型问题。

## 学习原则

1. 先理解“输入 → 处理 → 输出”，再看代码细节。
2. 每次只学一个概念。
3. AI 不直接替你思考；AI 先解释、再演示、再让你做一个小动作。
4. 不急着学 Transformer、神经网络数学、训练原理；那些属于后面的层。

## 第 0 课：我到底在学什么

目标：建立计算机项目地图。

你需要知道：

- 程序是什么。
- 文件夹是什么。
- Python 文件是什么。
- 运行一个程序是什么意思。
- 人脸识别项目的最小流程是什么。

## 第 1 课：认识一个 Python 文件

目标：看懂 Python 文件的骨架。

关键词：

- `import`
- `def`
- `main`
- `if __name__ == "__main__"`

小成果：

- 能指出一个 `.py` 文件里“导入工具”“定义功能”“开始运行”的位置。

## 第 2 课：命令行和文件路径

目标：知道自己在哪里、文件在哪里、怎么运行脚本。

关键词：

- `pwd`
- `ls`
- `cd`
- `python xxx.py`
- 绝对路径 / 相对路径

小成果：

- 能进入项目目录并运行一个 Python 文件。

## 第 3 课：Python 如何读取图片

目标：理解图片进入程序的第一步。

关键词：

- 图片路径
- OpenCV / `cv2`
- 图片宽、高、颜色通道

小成果：

- 能用 Python 打印一张图片的尺寸。

## 第 4 课：模型是什么

目标：把“模型”从神秘黑箱变成一个可调用工具。

关键词：

- 预训练模型
- 输入图片
- 输出检测结果
- 人脸框 bbox
- 置信度 score

小成果：

- 能用模型检测一张图片里有没有脸。

## 第 5 课：人脸特征向量是什么

目标：理解 embedding。

关键词：

- embedding
- 特征向量
- 512 维数字
- 余弦相似度

小成果：

- 能比较两张人脸图片是否像同一个人。

## 第 6 课：把脚本变成小工具

目标：从“代码能跑”变成“我会使用它”。

关键词：

- 命令行参数
- `--image`
- `--image2`
- 输出解释

小成果：

- 能运行 `face_demo.py` 并解释输出。

## 暂时不学或后面再学

这些不是现在的重点：

- Transformer 细节
- 深度神经网络数学推导
- 反向传播
- 模型训练
- GPU/CUDA 原理
- 向量数据库
- Web 后端部署

它们不是不重要，而是现在学会让你更晕。
